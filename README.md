# Movies API

Простой учебный API для каталога фильмов. Проект создан на FastAPI, данные хранятся в базе SQLite, а структура базы управляется с помощью Alembic.

## Основные возможности

- запуск веб-приложения на FastAPI;
- проверка работы API через корневой маршрут;
- хранение информации о фильмах в SQLite;
- асинхронное подключение к базе данных;
- модель фильма с проверкой рейтинга и года выпуска;
- добавление и получение фильмов;
- фильтрация по жанру, году и минимальному рейтингу;
- сортировка по названию, году или рейтингу;
- автоматическая документация Swagger и ReDoc;
- поддержка миграций базы данных через Alembic.

## Технологический стек

- Python 3.12;
- FastAPI;
- Uvicorn;
- SQLAlchemy;
- SQLite и aiosqlite;
- Alembic;
- Pydantic;
- Pytest.

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone <ссылка-на-репозиторий>
cd moves_api
```

Если проект получен архивом, его достаточно распаковать и открыть папку `moves_api` в терминале.

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация на Windows:

```bash
venv\Scripts\activate
```

Активация на Linux или macOS:

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Применение миграций

```bash
alembic upgrade head
```

### 5. Запуск приложения

```bash
uvicorn src.main:app --reload
```

После запуска приложение будет доступно по адресу:

- API: http://127.0.0.1:8000
- Swagger: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## Основные эндпоинты

### `GET /`

Проверяет, что приложение запущено и работает.

Пример ответа:

```json
{
  "message": "Movies API готов к работе!"
}
```

### `GET /docs`

Открывает интерактивную документацию Swagger.

### `GET /redoc`

Открывает документацию ReDoc.

### `POST /movies`

Добавляет новый фильм.

Пример тела запроса:

```json
{
  "title": "Интерстеллар",
  "genre": "Фантастика",
  "rating": 8.7,
  "year": 2014
}
```

### `GET /movies`

Возвращает список фильмов. Без параметров фильмы сортируются по названию.

## Фильтрация и сортировка

Для маршрута `GET /movies` доступны параметры:

| Параметр | Описание | Пример |
|---|---|---|
| `genre` | фильтр по жанру | `Фантастика` |
| `year` | фильтр по году выпуска | `2014` |
| `min_rating` | минимальный рейтинг от 0 до 10 | `8` |
| `sort_by` | сортировка по `title`, `year` или `rating` | `rating` |
| `order` | направление `asc` или `desc` | `desc` |

Пример запроса:

```text
GET /movies?genre=Фантастика&min_rating=8&sort_by=rating&order=desc
```

Параметры можно использовать отдельно или вместе.

## Модель данных

Таблица `movies` содержит следующие поля:

| Поле | Тип | Назначение |
|---|---|---|
| `id` | Integer | уникальный идентификатор фильма |
| `title` | String | название фильма |
| `genre` | String | жанр |
| `rating` | Float | рейтинг фильма |
| `year` | Integer | год выпуска |

## Ограничения базы данных

Для данных установлены следующие ограничения:

- `id` является первичным ключом;
- `title` и `genre` обязательны для заполнения;
- `rating` должен находиться в диапазоне от `0` до `10`;
- `year` не может быть меньше `1888`;
- для поля `title` создан индекс для ускорения поиска.
